# v0.5 frozen crop protocol

Recorded before computing candidate validation/test scores. Earlier aggregate test
results (56.0% original / 48.9% tight crop) have already been viewed; this is a
prospective selection protocol, not a pristine never-seen benchmark.

- Validation: 100 images per class from `train/`, selected by SHA256(seed=505,
  relative filename) order. Exclude exact decoded-pixel duplicates of any test
  image. No fitting or selection on `test/`. FER2013 has no participant IDs;
  subject-disjointness from pretrained training data cannot be verified.
- Detector: frozen YuNet weights, 192x192 linear-upscaled image, score=.6, NMS=.3,
  largest box. Detect ONCE per image and reuse the same boxes/5 landmarks for all
  variants. Save detection manifests. Invalid boxes are abstentions.
- Candidates, fixed now (selection pool): legacy tight AREA/[0,1]; tight
  AREA/[-1,1]; tight LINEAR/[-1,1]; tight CUBIC/[-1,1]; 10% and 25% per-side
  margin rectangular LINEAR/[-1,1]; square LINEAR/[-1,1]; eye-rotation-aligned
  square LINEAR/[-1,1]; source48 one-resize LINEAR/[-1,1] (box coordinates
  scaled back to original 48px). No test-guided margin search.
- Controls (not eligible for deployment selection): original full image
  AREA/[0,1], full LINEAR/[0,1], full AREA/[-1,1], full LINEAR/[-1,1],
  upsample/downsample full LINEAR/[-1,1].
- Select highest conditional macro-F1 on the common detected validation cohort;
  ties within 1e-12 resolved by candidate order above. Lock winner + protocol and
  data hashes to JSON BEFORE opening test labels for candidate scoring.
- Test: one frozen pass for every predeclared candidate/control, SAME detected
  IDs across all. Other test scores diagnostic only; never reselect winner.
- Metrics: accuracy, fixed-seven-class macro-F1, precision, recall, seven by
  eight confusion matrix (last column=abstention), ECE conditional on detections;
  end-to-end accuracy and macro-F1 count misses as false negatives. Bootstrap
  paired image delta is descriptive only (no known subjects for clustering).
- Engine: original Keras checkpoint batched on CPU; require NumPy-vs-Keras parity
  below 1e-5 on examples from both input-range profiles. Preserve legacy default.
- Checkpoints and arrays have hashes; all scores state profile + data provenance.
- Training-range correction is independently supported by upstream
  `src/utils/preprocessor.py` and `src/video_emotion_color_demo.py` (v2=True).
